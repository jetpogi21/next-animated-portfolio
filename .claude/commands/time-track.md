# Time tracking

Use for **this repo** when the maintainer wants a lightweight log of work sessions.

## Source

- **This repository** — default. Scope git history to the repo root (not another folder).

## Output

- Prefer **`docs/TIME-TRACKING.md`** at the repo root (create **`docs/`** if needed).
- Append dated sections: date, focus, commits or PR links, notes.

## Git (optional)

Summarize activity with **`git log --oneline -20`**, **`git shortlog -sn`**, or similar — follow **`.agents/skills/windows-shell-commands/SKILL.md`** on Windows.
