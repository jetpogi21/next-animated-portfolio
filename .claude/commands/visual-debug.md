# Visual debug

Use when layout, spacing, or pixel-level issues need confirmation.

## This repo

- **Dev server:** **`npm run dev`** — default **http://localhost:3000** (or the URL Next prints).
- **No Playwright yet:** capture **screenshots manually** or describe exact viewport sizes and elements to inspect in DevTools.

## When Playwright exists

Follow **`.agents/skills/galaxy-testing/SKILL.md`** for scratch specs and **`page.screenshot`**. Use **`.agents/skills/data-testid/SKILL.md`** for stable targets.
