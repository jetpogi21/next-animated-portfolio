# Handoff template

When finishing substantive work, include:

1. **What changed** — routes, components, or config touched (**`src/`** paths).
2. **Verification** — **`npm run lint`**, **`npm run build`**, and any manual URLs checked.
3. **Risks / follow-ups** — open questions or deferred items.
4. **Pointers** — relevant **`CLAUDE.md`** sections or **`.agents/skills/*/SKILL.md`** files if unusual patterns were used.

Optional: link to any design doc or issue the user provided (this starter has no bundled **`KANBAN-SPEC`**).
